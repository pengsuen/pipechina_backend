# 演示录音

本目录保存可以直接上传到项目交接班或会议模块的测试音频及对应文字稿，与知识语料一起作为开发夹具随仓库保存。

## 文件

- `项目全流程交接班录音_男声.wav`：中文男声交接录音，约6分18秒。
- `项目全流程交接班录音_男声_文字稿.txt`：录音原始文字稿，用于核对转写结果。

## 音频参数

- MIME类型：`audio/wav`
- 声道：单声道
- 采样率：24kHz
- 位深：16位
- SHA-256：`5dfc8f068e4190988e38552a9ad884d96782b7bf4a335b25aaa5a04301ecd37c`

录音内容包含交接班、生产事件、巡检发现、异常调查、维检工单、隐患治理、会议纪要、知识发布和生产日报，可用于验证上传、转写、摘要、事件抽取及后续业务流程。
